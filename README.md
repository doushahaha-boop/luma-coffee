# Luma Coffee — Portfolio Website

A responsive, single-page fictional coffee shop website built with HTML, CSS, and vanilla JavaScript.

## Included
- Responsive layout for desktop, tablet, and mobile
- Mobile navigation toggle
- Sections for brand story, menu, and visit/contact details
- Semantic HTML and basic SEO metadata
- CSS-only product illustrations (no image assets required)

## Run locally
Open `index.html` in a browser. For a local development server, use the VS Code Live Server extension or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before using as a client delivery
Replace the fictional business name, address, opening hours, menu, prices, email address, and social links. Confirm all content and contact details with the client.

## Deploy
This is a static website and can be published with GitHub Pages, Netlify, or another static hosting provider. No backend or database is included.

## Portfolio note
This is a self-initiated concept project for demonstration, not a commissioned client website.
